## 是什么

**文档事实** TP360 是 SmarTest 提供的工具；打开 TP360 后，可以从 App Center 标签页启动它提供的 function modules。

**文档事实** TP360 打开时显示 App Center 标签页；点击某个模块名即可在 TP360 中打开该模块。

**文档事实** 一个 TP360 session 只支持一个用户。

**文档事实** 模块标题旁的图标表示 SmarTest 当前状态（online 或 offline）与该模块运行环境不匹配。

**文档事实** 不要从 App Center 标签页的上下文菜单关闭 App Center。

**文档事实** 文档示例中，点击 App Center 的 Test Time Utilities 会打开该模块，其中包含 Configuration and Execution、Report、Console 三个视图，分别用于配置与执行、显示 HTML 结果报告、显示执行消息。

**推断** 因此 TP360 是一个以 App Center 为统一入口、把多个测试程序分析/工具模块组织在同一会话中的 GUI 外壳，各模块共享该 TP360 会话。

## 典型用法

**文档事实** 前置设置：把环境变量 `HP83000_ANNOTATE_MCDLog` 设为 1；不要设置环境变量 `HP83000_DISPLAY`。

**文档事实** 启动 SmarTest 并加载 test program，确认已加载的 testflow 已成功执行。

**文档事实** 用以下两种方式之一打开 TP360：在终端执行 `/opt/hp93000/TP360/run &`；或在主菜单选择 Applications > Advantest V93000 > TP360 for SMT7。

**文档事实** TP360 打开后，在 App Center 标签页点击模块名即可打开对应模块；模块的具体用法见 “Using TP360”。

**文档事实** 示例：点击 Test Time Utilities 后，可在 Configuration and Execution 视图进行配置和执行，在 Report 视图查看 HTML 结果报告，在 Console 视图查看执行消息。

**建议** 由于一个 TP360 session 只支持一个用户，多人协作时应避免同时打开同一会话。
